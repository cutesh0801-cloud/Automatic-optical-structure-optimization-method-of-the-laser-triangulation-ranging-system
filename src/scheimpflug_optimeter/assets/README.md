# Visual identity

`app_icon.svg` is the canonical Scheimpflug OptiMeter mark. It is an original
project asset drawn from the simulator's own laser, lens, tilted-sensor and
Scheimpflug-intersection geometry. It does not copy a manufacturer logo,
paper figure, product photograph or third-party icon.

`app_icon.png` is the 512 px runtime rendering and `app_icon.ico` is the
multi-resolution Windows application icon generated from that SVG. All three
files are distributed under the repository's Apache-2.0 license.
