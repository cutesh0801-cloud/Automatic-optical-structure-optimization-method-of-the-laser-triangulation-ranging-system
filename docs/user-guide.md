# 사용자 안내

Scheimpflug OptiMeter의 현재 범위는 `구조설계_rev.1.xlsx` 계산을 재현하는
Windows 시뮬레이터다. 계산 결과를 2D/3D로 시각화하고, 같은 광학 구조에서
정적 Basler 센서 규격별 FOV·샘플링·거리 민감도를 비교한다.

카메라 연결, 영상 취득, 레이저 선 검출, 보정, 단면 측정, 논문 전체 모델과
자동 구조 최적화는 현재 프로그램 범위가 아니다.

## 1. Workbook 계산 시트

프로그램은 `워크북 계산 · 실시간 2D` 탭에서 시작한다. 왼쪽은 Excel과 같은
행 중심 계산 시트이며 열은 `구분 | 한글 항목 | 변수 | 값 | 단위/출처`다.

셀 색의 의미:

- 연노랑: 사용자가 직접 편집하는 입력
- 연파랑: 렌즈·센서 정적 카탈로그 선택 또는 연동값
- 회색: 수식으로 계산되어 잠긴 결과
- 연빨강: 입력 오류 또는 계산 불가

주요 선택·입력:

| 항목 | 변수 | 동작 |
| --- | --- | --- |
| Basler 카메라 | `camera` | 정적 센서 규격만 선택 |
| 삼각측량 축 | `axis` | 센서 width/height 중 FOV 계산축 선택 |
| Edmund M12 렌즈 | `lens` | 공식 SKU 또는 프로젝트 사용자 프리셋 선택 |
| 초점거리 | `f` | 기본은 선택 렌즈와 연동, 연동 해제 시에만 직접 override |
| 기준 높이/거리 | `V` | Workbook 기준 거리 |
| Working distance | `d` | `R=V−d`와 표시 기준면에 사용 |
| 센서/이미지 길이 | `L` | 선택 센서축 연동 또는 직접 입력 |
| 수광각 | `α` | 기본 자동 계산, 필요할 때만 직접 입력 |

기본 `α` 모드는 `sin²α cosα=f/V`의 저각 해를 자동으로 구한다. 원본
Workbook의 반올림된 α를 정확히 재현해야 할 때만 `α 직접 입력`을 켠다.
`β`는 항상 `90°−α`로 계산되며 편집할 수 없다.

좁은 창에서는 숫자 입력 폭을 확보하기 위해 `구분`과 `단위/출처` 열을
숨기고 `한글 항목 | 변수 | 값`만 표시한다. 숨겨진 정보는 셀 툴팁에 남으며,
창을 넓히면 다섯 열이 다시 나타난다. `입력 연동`에서 `렌즈 f 연동`과
`센서 L 연동`을 끈 경우에만 해당 값을 직접 수정할 수 있다.

시트 아래의 `■ 설계 주요 공식` 카드에는 다음 핵심 관계식과 Known `f/V`,
계산 결과 표가 함께 표시된다.

```text
1/l₀ + 1/fₚ = 1/f
l₀ tan α = fₚ tan β
sin²α cosα = f/V
```

## 2. 2D 도면 읽기

2D 도면은 현재 계산 스냅샷 하나에서 생성되며 숫자 표와 별도 수식을
사용하지 않는다.

Workbook 좌표는 다음과 같다.

```text
기준점 T = (0,0)
레이저 발광점 E = (0,V)
CMOS 이미지 중심 I = (b,V)
```

따라서 화면의 CMOS 평면은 수평이고 수직 레이저 조사축에 직교한다. 화면의
`β`는 CMOS tilt가 아니라 수광축과 CMOS 사이의 유도 보각이다. 기울어진
평면은 수광축에 직교하는 렌즈 평면이다.

도면에는 다음 요소가 표시된다.

- 레이저 발광점과 조사 직선
- 기준점, `V`, `d`, 광선 교차 거리 `s`
- 수광축과 근·원거리 chief ray
- 렌즈 평면, 계산된 렌즈 주평면 위치, `l₀/fₚ`
- 수평 CMOS/이미지 평면과 `L`
- `b`, `W`, `R` 기구 외곽
- Scheimpflug 교점

마우스 휠로 확대·축소하고 드래그로 이동할 수 있다. `전체 구조`는 같은 물리
축척으로 장면을 맞추며, 먼 `s` 교점 때문에 광학 헤드가 지나치게 작아질 때는
헤드 중심 보기를 사용한다. 입력 오류가 나면 이전 정상 도면을 새 결과처럼
남기지 않는다.

## 3. 렌즈 위치, H/H′와 외형

Workbook은 H와 H′의 분리값을 계산하지 않는 얇은 렌즈 모델이다. 따라서
계산표와 광학 평면은 `H=H′`인 한 점을 사용한다.

공식 외형과 물체측 H 기준을 모두 확인할 수 있는 #58-206과 #83-954는 계산된
H 위치에서 렌즈 하우징의 전면, 단차, M12 나사부와 후면 위치를 역산한다.
Workbook의 `58206_002` 참조 렌즈는 #58-206 f/2.5이며, 기본 카탈로그의
#83-954 f/8과 다른 SKU다.

공급사의 H′ 값은 마지막 이미지측 광학면 기준이다. 하우징에 대한 마지막
광학면의 절대 datum이 없어 실제 H′ 위치나 H−H′ 간격은 추정하지 않는다.
렌즈 선택 행의 출처와 툴팁에서 Workbook 참조 여부를 확인할 수 있다.

### 사용자 렌즈 프리셋

내장 공식 카탈로그 항목은 제조사 기준값이므로 직접 덮어쓰지 않는다.
`프리셋 관리…` 메뉴에서 공식 렌즈를 `복제하여 편집…`하거나, 공식 출처를
상속하지 않는 `새 프리셋…`을 만들 수 있다. 사용자 프리셋은 같은 메뉴에서
다시 편집하거나 삭제할 수 있으며 원본 공식 항목에는 영향이 없다.

프리셋 편집 창에서 다음 값을 설정할 수 있다.

- 식별값: 프리셋 ID, 이름, 제조사, 제품 번호, 마운트, 나사 공차 등급
- 광학값: 초점거리 `f`, 조리개값 `F/#`, 이미지 서클, 파장 범위, 권장 WD,
  공간 해상력, BFL 범위
- 기구 외형: 최대 외경 `D`, 전체 길이 `OAL`, 전면 하우징 길이
  `L_front`, 나사부 길이 `L_thread`, 나사 바깥지름 `D_thread`, 나사
  피치 `P_thread`, 중량, 하우징 전면에서 첫 광학면까지의 깊이 `Front→S1`
- 주평면 자료: 부호 있는 `S1→H`, `SL→H′`

`S1→H`의 기준 `S1`은 물체측 첫 번째 광학면이고, `SL→H′`의 기준 `SL`은
상측 마지막 광학면이다. 둘 다 하우징 전·후면, 나사 어깨 또는 센서면 기준
좌표가 아니다. 이 기준면 종류는 프리셋에 함께 저장되며 다른 datum으로
바꿀 수 없다. 사용자 H/H′ 값은 검증된 외형 배치와 자료 표시에 쓰이지만,
Workbook의 얇은 렌즈 계산을 임의의 두꺼운 렌즈 계산으로 바꾸거나 알 수
없는 절대 H′ 좌표를 만들어 내지 않는다.

선택 치수의 `사용` 체크를 끄면 그 값은 0이 아니라 미입력으로 저장된다.
초점거리만 있는 광학 전용 프리셋도 계산에는 사용할 수 있다. 다만 실치수 3D
렌즈 외형은 필요한 기구 치수와 `S1→H`가 모두 있고 길이 관계가 일관될 때만
활성화된다. 값이 빠졌거나 서로 맞지 않으면 프로그램은 그럴듯한 형상을
추정하지 않고 실치수 외형을 비활성화하며, 화면에 해당 상태를 표시한다.
사용자 프리셋으로 저장한 수치는 공급사 검증값으로 표시하지 않는다. 원본
프로파일 ID와 제품 페이지는 유래 추적용으로 남길 수 있지만, 공식 도면 ID,
도면 검증일과 공식 도면 표시는 제거되어 2D/3D에서 `사용자 입력 외형 ·
공급사 검증 아님`으로 구분된다.

## 4. Basler 센서 비교

`Basler 센서 비교` 탭은 현재 광학 구조를 고정한 채 내장 센서 프로파일을
각각 다시 계산한다. 표에는 다음 값이 표시된다.

- 해상도, 픽셀 피치, 활성 크기, 문서상 최대 frame rate
- 가로·세로 물체측 FOV
- 가로·세로 평균 샘플링(µm/px)
- 근거리·중앙·원거리와 최악 거리 민감도(mm/px)

이 탭은 장치를 검색하거나 연결하지 않는다. 모델명은 정적 규격 행을
식별하기 위한 값이며 serial number나 연결 장치 ID가 아니다.

거리 민감도는 이상적인 기하에서 센서 한 pixel 이동에 대응하는 거리
변화량이다. 카메라의 양자효율, 신호대잡음비, 노이즈, 노출, 렌즈 MTF와
실제 측정 불확도는 포함하지 않는다.

## 5. 3D 보기

`3D Scheimpflug 시각화` 탭은 같은 Workbook 2D 계산을 깊이 방향으로 펼쳐
광학 헤드와 평면 관계를 확인하는 보조 보기다.

- 레이저, 센서, 수광축과 광선을 서로 다른 색으로 구분한다.
- 장면 내부에는 겹치기 쉬운 문자·수치·축 라벨을 그리지 않는다.
- 의미와 현재 상태는 캔버스 밖의 범례와 상태 카드에서 확인한다.
- 렌즈는 검증된 외형 데이터가 있으면 계산된 H를 기준으로 배치한다.
- 카메라와 발광기 몸체는 식별성을 위한 도식이며 제조용 CAD가 아니다.

`광학 헤드 확대`, `전체 구조 맞춤`, `기본 시점` 버튼과 마우스 회전·확대
기능을 사용한다. 3D는 별도의 pan/tilt 또는 full-focus 입력을 계산하지 않고
Workbook 2D 구조를 일관된 방향으로 표시한다.

## 6. 프로젝트, CSV와 그림 저장

프로젝트는 schema version 1의 `.scheimpflug.json` 파일이다. 사용자 입력,
정적 프로파일 선택과 보기 상태를 저장하며 파생 계산값은 열 때 다시 계산한다.
프로젝트 사용자 렌즈는 같은 파일의
`design_input.user_lens_presets` 컬렉션에 저장된다. 따라서 한 프로젝트에서
만든 프리셋은 전역 공식 카탈로그를 변경하지 않으며, 다른 프로젝트로
옮기려면 해당 `.scheimpflug.json` 파일을 함께 전달해야 한다.

`파일 > 워크북 입력 CSV 불러오기`는 첫 행을 읽는다. 현재 CSV 호환 형식의
필수 열은 다음과 같다.

```text
v_mm,d_mm,sensor_length_mm,alpha_deg
```

`camera_id`와 `sensor_axis`는 선택 열이다. CSV는 Workbook 회귀 호환을 위해
`alpha_deg`를 직접 입력 모드로 불러온다.

`파일 > 워크북 계산 결과 CSV 내보내기`는 입력과 계산 결과를 UTF-8 BOM
CSV로 저장한다. 2D 화면은 PNG 또는 SVG로 저장할 수 있으며 같은 계산
스냅샷을 `.snapshot.json`으로 함께 기록한다.

## 7. 해석 한계

시뮬레이션 결과는 Workbook 수식과 정적 제조사 규격을 기반으로 한 설계값이다.
실제 초점 위치, 조립 공차, 렌즈 왜곡·MTF, 센서 기울기, 어댑터 간섭, 레이저
안전이나 측정 불확도를 보증하지 않는다. 실제 제작 전에는 광학·기구 도면과
실물 측정으로 별도 검증해야 한다.
