# 사용자 안내

## 1. 워크북 계산과 실시간 2D

프로그램은 `워크북 계산 · 실시간 2D` 탭으로 시작합니다. 다음 네 값을
`구조설계_rev.1.xlsx`와 같은 단위로 입력합니다.

- `V` — 워크북의 전체 기준 높이(mm)
- `d` — 워킹 디스턴스 기준값(mm)
- `L` — 계산에 사용할 이미지/센서 길이(mm)
- `α` — 수광각(degree)

`L`은 사용자가 입력한 값이 계산의 권위값입니다. `센서 규격 프로파일`에서
`Basler ace acA1300-60gm`과 사용할 축을 선택한 후
`선택 프로파일 L 불러오기`를 누르면 정적 규격값 6.7946 mm 또는
5.4378 mm를 `L`에 복사할 수 있습니다. 프로파일 선택은 장치 검색이나
연결을 수행하지 않으며, 프로파일을 바꿔도 기존 `L`을 자동으로 덮어쓰지
않습니다.

결과 표에는 `β`, `b`, `x=L/2`, `W`, `R`, `fp`, `lo`, `s`,
유도 초점거리 `f`, `lo+fp`가 모두 나타납니다. 가운데 2D 화면은 같은
계산 스냅샷에서 다음 항목을 즉시 갱신합니다.

- 레이저 조사 직선과 워킹 디스턴스
- 렌즈 평면, 수광 광축과 chief ray
- 실제 이미지/센서 평면
- Scheimpflug 교점과 `W/R`

입력 오류가 발생하면 이전 정상 도형을 현재 결과처럼 유지하지 않습니다.
전체 워킹 디스턴스는 `전체 맞춤`, 렌즈·이미지 평면 부분은
`광학 헤드 확대`로 확인합니다.

## 2. CSV로 한 시나리오 교환

`파일 > 워크북 입력 CSV 불러오기`는 첫 데이터 행을 계산 입력으로
사용합니다. 필수 열은 다음과 같습니다.

```text
v_mm,d_mm,sensor_length_mm,alpha_deg
```

선택 열 `camera_id`는 정적 센서 규격 프로파일 ID이며 장치 ID나 serial이
아닙니다. `sensor_axis`에는 `height` 또는 `width`를 사용할 수 있습니다.
결과는 `파일 > 워크북 계산 결과 CSV 내보내기`에서 입력과 모든 워크북
산출값을 한 행으로 저장합니다. CSV는 UTF-8 with BOM으로 작성되어 한글
Windows Excel에서도 바로 열 수 있습니다.

## 3. 프로젝트와 그림 저장

프로젝트는 schema version 1의 `.scheimpflug.json` 파일입니다. 계산 입력,
정적 규격 선택과 보기 상태만 저장하며 모든 파생값은 다시 열 때 현재 계산
엔진으로 재계산합니다. 2D 구조는 SVG 또는 PNG로 내보낼 수 있고, 동일
계산 스냅샷 JSON도 함께 생성됩니다.

## 4. 3D와 고급 계산

`3D Scheimpflug 시각화` 탭은 렌즈 평면, 이미지/센서 평면, 레이저 평면,
물체 평면과 Scheimpflug 교선을 공간상에서 보여줍니다. 탭이 보이지 않을
때는 Matplotlib 렌더링을 미뤄 기본 2D 입력 응답성을 유지합니다.

워크북 계산 이외에 비교가 필요할 때만 다음 기능을 사용합니다.

- `Canonical 설계` — 독립 `α/β`, 렌즈 후보와 비대칭 결상 비교
- `구조 최적화` — SciPy differential evolution과 재현형 M-PSO

이 고급 계산도 수치 시뮬레이션이며 실제 장치를 제어하지 않습니다.

## 5. 프로그램 범위

이 프로그램에는 카메라 연결, 영상 미리보기, 촬영, 내부·외부 보정,
레이저 선 검출, 단면 측정 기능이 없습니다. `acA1300-60gm`을 포함한
모델명은 오직 센서 치수·픽셀 피치·마운트 같은 정적 설계 입력을 고르는
데 사용됩니다.

시뮬레이션 결과는 기구 간섭, 실제 초점 성능, 제조 공차 또는 레이저 안전을
보증하지 않습니다.
