# 사용자 안내

## 1. 기본 흐름: 워크북 계산과 실시간 2D

프로그램은 `워크북 계산 · 실시간 2D` 탭으로 시작합니다. 다음 네 값을
`구조설계_rev.1.xlsx`와 같은 단위로 입력합니다.

- `V` — 워크북의 전체 기준 높이(mm)
- `d` — 워킹 디스턴스 기준값(mm)
- `L` — 계산에 사용할 센서/이미지 길이(mm)
- `α` — 수광각(degree)

`L`은 사용자가 입력한 값이 계산의 권위값입니다. acA1300-60gm의 센서
높이 `5.4378 mm`를 쓰려면 `카메라 축 길이 불러오기`를 누를 수 있지만,
카메라 선택을 바꿔도 입력한 `L`을 자동으로 덮어쓰지 않습니다. 따라서
워크북의 `L=3.0 mm` 사례도 그대로 재현할 수 있습니다.

결과 표에는 `β`, `b`, `x=L/2`, `W`, `R`, `fp`, `lo`, `s`, 유도 초점거리
`f`, `lo+fp`가 모두 나타납니다. 가운데 2D 화면은 같은 계산 스냅샷에서
다음을 즉시 갱신합니다.

- 레이저 조사 직선과 워킹 디스턴스
- 렌즈 평면, 수광 광축 및 chief ray
- 실제 이미지/센서 평면
- Scheimpflug 교점과 `W/R`

입력 오류가 발생하면 이전 정상 도형을 현재 결과처럼 유지하지 않습니다.
전체 워킹 디스턴스는 `전체 맞춤`, 렌즈·센서 부분은 `광학 헤드 확대`로
확인합니다.

## 2. CSV로 한 시나리오 교환

`파일 > 워크북 입력 CSV 불러오기`는 첫 데이터 행을 계산 입력으로
사용합니다. 필수 열은 다음과 같습니다.

```text
v_mm,d_mm,sensor_length_mm,alpha_deg
```

선택 열 `camera_id`, `sensor_axis`도 사용할 수 있습니다. 결과는
`파일 > 워크북 계산 결과 CSV 내보내기`에서 입력과 모든 워크북 산출값을
한 행으로 저장합니다. CSV는 UTF-8 with BOM으로 작성되어 한글 Windows
Excel에서도 바로 열 수 있습니다.

## 3. 프로젝트와 그림 저장

프로젝트는 schema version 1의 `.scheimpflug.json` 파일입니다. 입력과
선택값만 저장하며, 모든 파생 계산값은 다시 열 때 현재 계산 엔진으로
재계산합니다. 2D 구조는 SVG 또는 PNG로 내보내며 동일 계산 스냅샷 JSON도
함께 생성합니다.

## 4. 고급/연구 참고 기능

다음 화면은 기본 워크북 계산에 필수적이지 않습니다.

- `Canonical 설계`: 논문식 독립 `α/β`, 렌즈 후보 및 정확 비대칭 결상
- `구조 최적화`: SciPy differential evolution과 재현형 M-PSO
- `고급/연구 참고 · 3D`: full-focus, Scheimpflug/hinge line 비교
- `고급/장비`: Basler/모의 카메라, 보정 및 단일 프레임 단면 측정

Canonical 모드를 선택해야 최적화 패널이 나타납니다. 3D 탭이 비활성일
때는 최신 계산값만 보관하고 Matplotlib 렌더링을 지연하여 기본 2D 입력
응답성에 영향을 주지 않습니다.

## 5. 하드웨어와 안전

acA1300-60gm은 C-mount 카메라입니다. M12 렌즈에는 C-to-M12 어댑터와
별도의 Scheimpflug 틸트 기구가 필요합니다. 녹색 계산 결과가 배럴,
어댑터 또는 기구 간섭이 없음을 의미하지는 않습니다.

이 애플리케이션은 레이저 제품 등급이나 안전을 보증하지 않습니다.
적절한 파장용 차폐와 보호 장비를 사용하고 설치 지역의 규정을 따르십시오.
